# 抓取、落点和返程经验

[English](manipulation.md) | 中文

本文只描述通用操作方法，不提供现场尺寸、位姿、关节角或夹爪开度。首次执行从当前图像、反馈和标定求解；成功后按 [经验数据约定](experience.zh.md) 保存实测结果。

## 放子位置更准

在归位状态先给 19×19 网格编号，保存当前黑白棋和唯一目标空交点，在左头图副本标记。高位转运到目标附近后，再用右腕图里邻棋的行列和纵横网格线确认同一个交点；主要 XY 修正在预览高度完成，最后沿同一竖线下降。

由当前标定得到的网格间距可用于粗定位和目标一致性检查，不能当作实际落盘精度。棋子顶面圆心、夹爪画面中心和很小的 TCP 跟踪误差，都不能单独证明棋子对准棋面交点。

## 抓取第一次闭合更可靠

把对准修正提前到首次闭合前：先在预览位校正，再在低位复核双指内缘、棋心和指尖接触线，最后慢收。

关键是判断条件提前，而不是保存一个固定 XY 偏移。下降会改变透视：预览位居中，低位仍可能贴某一侧指尖。每次都根据当前画面校正；抓取失败后以被扰动棋子的当前位置为准。夹爪闭合角度不是成功证据，短抬升后必须看到单颗棋子随爪、桌面原位为空、邻近供子未动，才转运。

## 抓子对准时的“之”字型臂形先验

抓子对准时，优先比较肩、肘、腕配合形成的“之”字型臂形分支。这里的“之”字是整条肩—上臂—肘—前臂—腕的空间形状，不是只把夹爪转到朝下，也不能只凭肘角正负判断。规划抓子接近前就读取本节，用头图核对臂形、腕图核对指尖与棋子，再用关节反馈确认分支。

在供子区高位接近后降到预览位，保持夹爪朝下，完成少量 XY 修正后沿同一竖线下降。低位抓稳后只短抬升核验，再规划高位转运。不要为“先抬起来”不断增加高度、翻腕或让肩肘切换到另一组 IK 解，直到腕关节贴近限位才处理。

Agent 规划时按以下顺序处理：

1. 从当前实测关节和任务腰角出发，先确定供子区安全通道、预览位与夹爪朝向。核对头图中的整条右臂形状，避免只盯 TCP 或腕图中心。
2. 比较候选解的肩 yaw、肩 roll 和腕部配合，保持左臂固定。已有经验只有在机器人、场景、配置和标定一致时才可辅助求解，不能冒充当前反馈或执行计划起点。
3. 在安全空间内生成从实际起点到候选分支的连续路径，检查整段净空、速度、关节余量及后续下降和短抬升是否可达。不能只检查终点，也不能直接从当前姿态跳到缓存的关节向量。
4. 用相邻已通过检查的解逐段接近、下降及短抬升。若需换分支，先在已审阅的安全通道内完成；接近棋子后不临时翻腕或大幅抬肩。调整高度或朝向时重查指尖接触线和全部后续阶段。

臂形相似不代表远离限位。检查整段路径和后续下降、短抬升的关节余量，不能为了外观相似放宽限位；没有合适解时，在安全位置调整接近方案。

当前 `Kinematics.solve()` 只有关节硬限位和很弱的接近输入 seed 项，没有“之”字型偏好、关节余量软约束或自动多分支选优。标准动作工具的 seed 来自当前控制状态，所以仅记录相同 TCP 不保证得到相同臂形。上述选解与臂形复核是宿主 Agent 的规划要求，本文不代表求解器已经自动实现。

## 归位准备更快

把返程准备放在用户确认之前。低位沿本轮落子竖线向上，高位反向复用本轮已执行、已核对净空的来路，接到已审阅的归位通道。最终 XY 若改变，只需先重建相应短连接，再核对整条路径的连续性、关节边界、腰角和左臂保持。旧轮路线不能直接重放。

确认后同一控制会话连续慢开、抬升、退出、归位，不再临时求解路线。评估耗时时应分别记录规划时间、计划运动时长和实际完成时间。运行时仍须检查新鲜反馈、故障和计划起点。

## 其他改进与证据边界

- **减少悬空**：归位时处理判断和记录，低位避免长期等待。遇到 stale DDS state 等保护退出时，依据反馈和故障日志排查，不凭单个温度读数判断原因。
- **高度只作先验**：抓取、短抬升、放子和预览高度由当前场景求解，成功后分别记录为经验，分段垂直接近。TCP 高度不是接触面的测量值。
- **分清姿态表示**：俯仰接近 90° 时 Euler 角不唯一，比较旋转矩阵或旋转误差。关节归位通过不等于 TCP 笛卡尔到位。
- **图像拟合不等于落子精度**：单张图像的网格单应矩阵拟合残差只描述图像拟合质量，不能作为实际落子精度。
- **中断后重新核验**：区分接近、闭合、抓稳和放子等阶段；中断前的位姿和授权状态不能被当作当前状态。
- **完成报告分项**：归位反馈通过不代表精确落点已做视觉验收。保护退出不能报告为正常主动断开，也不能推断断开后的实时姿态。

这些经验用于 [自主执行流程](autonomous_play.zh.md) 和 [操作规则](operating_guide.zh.md)。宿主 Agent 实际看图、精调与检查净空，自动引擎选点；控制与采集层见 [硬件接入](hardware_integration.zh.md)。
