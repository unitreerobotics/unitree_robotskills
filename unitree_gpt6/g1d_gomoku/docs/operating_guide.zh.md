# 执黑下五子棋：操作规则

[English](operating_guide.md) | 中文

这是自主五子棋的操作约定，由宿主 Agent 配合自主轮次工具执行。Agent 看图识别棋局、完成视觉对准与净空检查，引擎自动选点，硬件工具执行机械动作与反馈。具体衔接见 [自主执行流程](autonomous_play.zh.md)。

## 任务

机器人执黑，每轮用右臂、右夹爪从桌面供子区抓一颗黑棋放到当前选定的空交点，随后 `reset_right`。选择供子区中单独、可见且可达的一颗，不从棋盒取棋，不移动棋盘上的已有棋子。保持任务启动时的腰角，夹爪不得碰撞桌面、棋盘或其他棋子。

自主闭环使用 `cam_left_high`、`cam_right_high`、`cam_left_wrist`、`cam_right_wrist` 四路原图，以及双臂、腰部和夹爪反馈。硬件工具提供这些数据源，由宿主 Agent 实际读取和复核。

## 五子棋规则

19×19 棋盘，黑先白后，双方交替，每手只在空交点落一颗棋子。已有棋局从当前回合继续。默认无禁手，同色沿横、竖或两条斜线连续五颗及以上获胜。棋子落下后不移动、不吃子；桌面供子不计入棋局。每完成一手黑棋后归位，等待白方落子和用户启动下一轮。

## 棋局判断与落点标注

归位时用两路头部原图交叉核对棋盘、网格和棋子。以左头图方向为准：行从上到下，列从左到右，编号从 1 开始，外框不算网格线。定位棋面交点，不把棋子顶面的投影当成交点。

将当前完整识别结果提交给自动选点引擎：先找黑方本手成五的机会，再处理白方下一手成五的威胁，其余情况兼顾攻守。两端都堵住的连四不算直接胜势。目标必须是当前局面中的唯一空交点。

每手建立独立运行目录，保存四路原图、落点标注和 `position_and_move.json`。标注图只圈一个交点，注明“黑落点”、行列和简短理由；JSON 记录坐标约定、黑白棋行列、目标行列与原图像素、理由和图像路径。实际放子须与记录一致，棋局改变后重新判断。只要求判断时交付标注即可，要求执行时继续完整取放流程。

## 位姿和高度

TCP 采用 pelvis 坐标系 `[x, y, z, roll, pitch, yaw]`，位置为米，角度为弧度，旋转为 `Rz(yaw) @ Ry(pitch) @ Rx(roll)`。TCP 由包内模型的末端定义确定，既不是指尖也不是棋心；规划要补偿夹爪长度、姿态与持棋偏移。俯仰接近 90° 时比较实际旋转，不只比较 Euler 数值。

工程不提供抓取、预览、短抬升、放子高度或夹爪开度的经验默认值。首次从当前图像、反馈和场景标定求解，成功后写入工作空间的结构化经验。`target` 与 `measured` 必须分开，图像、实测姿态和反馈决定当前最终位姿。不要把 TCP 高度当成桌面、棋盘或棋子的表面高度，也不要让用户承担相机与本体标定。

## 执行流程

开始先归位，保存四路原图和机械臂、腰部、夹爪状态。一手分为四个机械阶段：

1. **桌面取棋**：安全高度到棋子上方，在预览位修正，再低位核对双指内缘、棋心与指尖接触线。保持臂位慢收，短距离垂直抬升，确认只带起一子、原位变空、邻近供子未扰动。抓空或棋子移位后按当前图像重定位。
2. **高位转运**：先估计目标 XY、持棋偏移并核对净空，再从安全高度到目标附近上方。用右腕图的邻棋和纵横网格线精调，在低位前完成主要修正。
3. **准备放置**：核对空交点，沿同一 XY 分段下降。用户确认前就准备完整返程：沿落子线垂直抬升，反向使用本轮已执行且复核净空的高位路线，再接归位通道。最终 XY 改变后重新校验连接段。向用户说明落点、释放和返程，取得松爪确认。
4. **连续归位**：确认后在同一健康控制会话中慢开夹爪，立即连续抬升、退出棋盘并归位。放子后不临时规划返程或更换发布器，必要的运行时健康和起点检查仍须保留。

## 注意点

在归位时完成棋局判断和主要路线准备，减少悬空等待。先快速到目标附近上方，尽量用一两次有依据的精调对准，不在棋盘低位长期思考。

抓取时夹爪保持垂直桌面，两指可轻触桌面但不能撞击。腕相机与夹爪不平行，不能只看画面中心。首次微调前，用本轮已执行位姿变化和相对指尖的图像位移判断 X/Y 调整方向及比例；每修正一次就复核一次。预览位看似居中不代表下降后仍居中。慢收前让两指均衡接触，避免把棋子弹开。

取子和转运可按已授权任务自主执行，用户确认点设在对准后、松爪前。确认后只保存一次四路图像，不查看、不分析、不等视觉确认；随后不再采图，只保留必要的控制反馈，连续抬升归位。因此完成报告不能声称放子后的精确交点已经视觉验收。

普通执行偏差应记录、修正并继续完成本手。失联、保护停机或碰撞风险出现时先停止后续运动并查清状态，不能把未完成动作报告为成功，也不能盲目重放旧目标。

## 约束和记录

棋盘外沿、网格间距、桌面与棋面高度由当前场景标定确定。已有经验仅作候选参考，每轮按当前棋局、腰角、图像、持棋偏移及净空重新核对。

执行前说明动作与完整目标 TCP，结束后记录实测 TCP。松爪确认前按阶段保存原图、双臂/腰/夹爪反馈、计划和结果；确认后的图像只保存一次。默认不录制视频。对外说明目标与结果即可，参考查阅过程留在后台记录。

通用方法见 [操作方法](manipulation.zh.md)，成功数据按 [经验数据约定](experience.zh.md) 保存。区分关节归位、TCP 到位、释放完成和棋面落点验证；其中一项通过不能替其他项背书。
