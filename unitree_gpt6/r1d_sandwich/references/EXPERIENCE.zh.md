## 分工与服务边界

- Agent 负责看图、估计位置、选择下一个路点并判断结果。
- 服务负责 IK、关节限位、自碰撞间隙、桌面间隙、已登记的障碍盒、单次运动位移、执行和看门狗。
  被拒绝的路点没有产生运动。
- 服务检查的内容：关节限位余量 `0.03` rad，自碰撞间隙至少 `20` 毫米，TCP 至少高出桌面 `15` 毫米，
  桌面上方的手臂连杆至少高出桌面 `50` 毫米，单次运动 TCP 位移最大 `0.6` m。
- 服务不知道盘子、食物、松散物体或人在哪里。它无法确认夹持力、物体是否附着、是否接触盘子或最终
  放置结果。
- 看门狗触发后会锁存 `stopped`。不要从 Agent 一侧清除；报告它，由操作员处理故障。
- 固定的升降和手臂姿态可能让电机在两次调用之间持续受力。推理或评估候选路点时，不要停在受力姿态下
  不动。

## 坐标系、TCP 与夹爪几何

- 位置使用 R1-D URDF 基座坐标系，单位为米：x 向前，y 向左，z 向上。
- TCP 是 Dex1 两个指垫之间的中点。在标准位姿下，工具 x 轴沿手指方向，工具 y 轴沿开合方向，
  工具 z 轴向上。
- `rpy_deg=[r,p,y]` 表示基座坐标系下 `R = Rz(y) * Ry(p) * Rx(r)`。
- 指尖超出 TCP `2.33` 厘米，手指半高为 `2.0` 厘米。手指与竖直方向成 `t` 度时，手指最低点比 TCP 低
  `drop(t) = 0.0233*cos(t) + 0.020*sin(t)` 米。
- 计算夹取高度时要减去这个下探量。第一次三明治尝试中漏掉了它，手指插得太深，夹爪顶在烤面包机内壁上
  堵转。
- 开度范围从 `0`（闭合）到 `1`（全开，约 9 厘米）。夹物体用 `action="grasp"`。不要用持续的开度 0
  指令去挤压物体；这可能触发夹爪故障。
- 夹取后报告的开度是证据，不是证明。对面包，`0.13` 到 `0.20` 表示夹住了面包片，`0.02` 到 `0.06`
  表示夹空。薄叶子被夹住时开度也可能很小，所以还要看腕部图像。

## 相机使用

- 标定过的头部相机在手臂不遮挡时适合看盘子、生菜和面包。在参考布置下，它在桌面平面上的误差约为
  `1.2` 厘米。
- 头部相机看不到 `x < 0.37` 的桌面位置。手腕或前臂挡住目标时它也会失效。
- 腕部相机用于近距离对准。斜着看的腕部视角会夸大位置误差。把手放到目标上方，在固定升降允许的范围内
  尽量向下看。
- 两路腕部相机的标定相差约 3 厘米。手里的物体和它的目标要用同一路腕部相机测量。
- 烤面包机的槽从右腕看比从斜向的头部视角看更可靠。第三次运行中，烤面包机定位和第一片面包耗去
  `19.8` 分钟和 `31` 次模型调用。
- `z = 0.867` 的高位腕部视角低估了横向误差。看上去 40 像素的偏移实际是 1.5 厘米，造成两次夹空。
  闭合前先把张开的夹爪降低，再看一次。
- 盘子或物体被图像边缘截断时，掩膜中心会偏向可见的那一部分。使用完整的目标视图，或根据远侧盘沿和
  已知半径重建中心，然后用标尺标记核对估计值。

## 路线经验

- 阶段之间只用关节空间 `home`。用末端位姿返回时选中了另一个 IK 分支，肩外展约 48 度，肘部朝外。
  右肩偏航电机随后承受约 4 Nm，而标准位姿下是 0.8 Nm，温度达到 84 C。
- 每个阶段都从核对过的关节姿态出发。发送新路线之前，用 `bash r1d eval` 比较姿态和可达性。
- 平放面包松手时，从盘子右侧以 rpy `[90, -10, 20]` 进入，肘部保持在肩部以下。另一组 rpy
  `[-90, 10, 75]` 会把肘部抬到肩部以上。
- 在固定升降下伸进烤面包机需要约 80 度的肩外展。对准和夹空让这个姿态在第三次运行中持续了 99 秒，
  在第二次运行中持续了 40 秒。不要转腰来补偿。
- 取走第一片后，剩下的那片在图像里的位置会变。下一次夹取之前，以及插入第二片之前，都要重新读它的
  位置。
- 生菜要高位搬运。第一次运行中，低位的关节空间搬运把两个盘碟都朝机器人方向推了约 5 厘米。服务没有
  对盘碟建模。
- 一只手拿着物体停在盘子上方时，不要移动另一只手臂。
- 数值反馈（如 TCP 位置、开度和拒绝码）能回答问题时就用数值反馈。每读一次图都要消耗一次模型调用。

## 出现过的失败情况

| 现象 | 原因 | 恢复方法 |
|---|---|---|
| 进入烤面包机后夹爪故障 | 夹取高度没有考虑手指下探量，或手指碰到了内壁 | 重新计算高度，使用 `grasp`，重试前先张开并退出 |
| 面包两次夹空 | 头部估计或高位腕部视角低估了横向误差 | 降低张开的夹爪，查看右腕图像，修正偏移，然后闭合 |
| 面包落在盘沿上 | 盘子中心因遮挡而偏移 | 取一张完整的头部视图，或用远侧盘沿重建，然后用 `look --mark` 核对 |
| 松手时拖拽或刮擦 | 松手高度太低，平放的面包片仍然倾斜 | 保持在支撑面上方测得的间隙，完全张开前先滑出 |
| 右臂返回时被烤面包机挡住 | 路线在低处穿过了已登记的障碍 | 沿已验证的退出点走，烤面包机挪动后核对障碍盒 |
| 左肘升到肩高 | 夹生菜和近距离搬运需要倾斜的接近方式 | 使用核对过的生菜路径，不要在受力姿态下停留 |
| `linear: true` 在可达边界附近被拒绝 | 直线段离开了可达范围 | 用 `linear: false` 退回前一个悬停点，再沿核对过的路线靠近 |
| `joint jump` 或分支翻转 | 目标朝向离当前 IK 分支太远 | 改变 yaw，或经过一个核对过的过渡点接近 |
| 前一条命令被拒绝后，后一条命令仍然执行了 | 带管道的命令返回的是管道末尾命令的状态 | 有依赖关系的命令用 `set -o pipefail` 和 `&&` |

## 运行纪律

- 第一次运动前读取 `state`，记录起始温度。
- 运行前检查整个场景：两只手都在桌面上方，腰接近零位，模式是已授权的模式，没有锁存的停止，
  硬件急停触手可及。
- 把面包搬到盘子上方之前，把放置和退出的候选路点一起预演。第三次运行中有七个放置或退出路点被拒绝。
- 夹取和放置的前后各保存一个关键帧。图像确实显示出预期结果之前，不要把关键帧命名为 final。
- 如果服务重启、日志目录改变，或在手里拿着物体时有其他操作员移动了手臂，就停下并报告这一不一致。
- 报告已完成的动作、图像结论、夹取开度、被拒绝的情况、实测放置偏差、温度和指标路径。缺少证据时
  直接说明，不要推断成功。

### 盘子太近

依据：运行 `20261124-204332-real-eef-cc`，盘子中心在 `(0.284, -0.02)`，后侧盘沿在 `x = 0.167`：

- 平放松手的 TCP 比约 `(0.34, -0.06)` 更靠近机身时被拒绝（升降柱与右肩连杆之间只有 `17` 到 `20`
  毫米；yaw `30` 时关节 12 到达限位）。第一片落在越过盘子中心 `3.7` 厘米处，上层那片又比下层那片远
  `8` 厘米，只有一个角搭着。这次运行被放弃。
- 推盘需要 TCP 位于后侧盘沿后方 `4` 厘米处，这里是 `x = 0.127`。离线通过的最近位姿是 `x = 0.178`。

下一次运行中盘子中心在 `(0.341, -0.026)`，同样的命令把第一片放在距盘子中心 `1.7` 厘米处，上层那片
距下层那片约 `2` 厘米，双手推盘也通过了。

### 面包：12 厘米面包片

选择上拉高度之前先测量面包片。第四次运行（2026-11-24）用的面包片约为 `12 x 12` 厘米，不是
`9 x 9`。上拉到 `z = 0.885` 时底边还在槽口高度，随后的搬运拖动烤面包机并把它带倒，两片都是这样。
Agent 没有发现：上拉之后它一直没有看烤面包机。

夹取成功后使用这条路线。它已用 `bash r1d eval` 离线核对过，夹取点为 `(0.52, -0.28)`，yaw `-5`：

1. 直线上拉到 `z = 0.92`。这是升降 `0.522` 时的可达边界；`0.94` 被拒绝。
2. 原地翻平：关节插值到同一位置，rpy 为 `[90, -10, yaw]`。面包片会摆起到 TCP 高度，手的下方不再有
   东西垂着。面包片还竖着时不要平移或下降：在 `z = 0.92`，以 rpy `[0, 8, yaw]` 朝机身方向的任何
   横向移动都不可达。
3. 关节插值到 `(0.45, -0.15, 0.80)`，rpy `[90, -10, 15]`。
4. 关节插值到盘子上方的悬停点（见“平放”）。

旧路线（上拉到 `0.885`，直线到 `(0.46, -0.29, 0.87)` rpy `[0, 8, -12]`，再关节插值到
`(0.40, 0.0, 0.84)` rpy `[0, 5, 15]`）只适用于 `9` 厘米的面包片。

两个槽都装着面包时，两片相距约 `4.9` 厘米。夹爪为 `0.45` 时，外侧手指会落在相邻的面包片上；接近时
用夹爪 `0.32`，让那根手指能插进两片之间。

第四次运行的第二次尝试（2026-11-24，运行 `20261124-151802-real-eef-cc`），使用这条路线：

- 两片都取出来了，没有碰到烤面包机。夹取点为 `(0.52, -0.290)` 和 `(0.52, -0.334)`，
  yaw `-3`，开度 `0.188` 和 `0.174`。
- 在可达边缘附近，直线下降 `0.82 -> 0.79` 可能被当作分支翻转而拒绝。在 `0.805` 处拆成两段后通过。
- 翻平位姿很敏感：左槽用 `[90, -10, -8]` 通过，右槽用 `[90, -10, -15]` 通过；
  `[90, -10, 0]` 被拒绝。
- 从右槽出发，手臂到达 `(0.45, -0.15, 0.80)` 时，上臂刚好低于 `20 mm` 的自碰撞余量。此后服务拒绝了
  从该位姿出发的所有运动，包括 `home`，操作员只能用手把肘部向外挪开一点。再次使用这个点之前，先从
  右槽的翻平位姿预演它，并选一个间隙更大的途经点。
- 盘子在约 `(0.415, -0.02)` 时，`z = 0.66` 的松手被拒绝（手腕高出桌面 `49 mm`）；`z = 0.68` 通过。
  松手 TCP `(0.385, -0.078)` 使第一片的中心落在约 `(0.405, -0.02)`：对 `12` 厘米的面包片，偏移为

- 第二片放在生菜上面，用同样的松手 TCP，结果它相对第一片朝 `-y` 偏了约 `3.8` 厘米。松开第二片之前，

- 第三次尝试（运行 `20261124-154720-real-eef-cc`）：没有碰到烤面包机或盘子，也没有被拒绝。

  `link_gap_min_per_wp` 是桌面间隙，不是自碰撞间隙），所选路线在每个路点都至少有 `27 mm`。
  从翻平位姿直接去盘子上方的悬停点，rpy `[90, -10, 10]`；跳过途经点 `(0.45, -0.15, 0.80)`。

  夹取点在 `x = 0.52` 时，工具坐标系下的偏移约为 `(0.069, 0.022)`，而不是 `(0.039, 0.048)`。
  在松手前悬停点，在 `z = 0.70` 处标出预测的面包中心，松手前修正 TCP。第一片这样做了（中心距盘子
  中心约 `2.5` 厘米以内），第二片跳过了这一步，结果落在距第一片约 `3.9` 厘米处。
- 第四次尝试（运行 `20261124-160921-real-eef-cc`），路线相同，命令合并后数量更少：没有接触，
  没有被拒绝，每样都是一次夹住。在松手前悬停点检查手里的面包片并没有消除上层那片的偏移（仍然约
  `4` 厘米）。下侧手指滑出时，面包片会朝机器人方向退回 `3.6` 到 `6` 厘米，而且这个位移不可重复。
  下一步要试的：上层那片用更低的松手高度，或在滑出之前完全张开。
- 生菜小碟在约 `(0.51, 0.28)` 时，rpy `[0, 35, -45]` 够不到；`[0, 45, -37]` 通过，并在松手点用
  关节插值下降。

第五次和第六次运行（2026-11-24，运行 `20261124-172023-real-eef-cc` 和 `20261124-181646-real-eef-cc`）：

- 不要跳过松手前悬停点的那次看图。第六次运行为了省时间跳过了它：第一片落在越过盘子中心 `6` 厘米处，
  压在远侧盘沿上，补救用了 `253` 秒。用手指侧面把放好的面包片往回拨，只挪回 `1.5` 厘米，还把盘子
  拖动了 `0.7` 厘米。
- 只根据 `z = 0.805` 的低位视图判断手指在面包片长度方向上的位置。`z = 0.87` 的高位视图显示面包片
  比实际近约 `5` 厘米，于是手向后移，夹在了面包片的后端。松手后面包片相对 TCP 就会向前多出这么多。
- 面包片在槽里歪着时，让手对准面包片，而不是对准槽：yaw `12` 时夹空（开度 `0.023`），改为
  yaw `6` 并把接近开度从 `0.32` 加大到 `0.55` 后夹住了。

第七天的运行（2026-11-25，运行 `20261125-162207-real-eef-cc`），烤面包机比前一天远约 `4` 厘米。
当天更早的两次尝试都夹空了（开度 `0.023`、`0.024`），被放弃：

- 头部相机把手引到了两片面包之间：在低位视图里，两片面包都在两指之间的空隙里。要从腕部视图选
  面包片，不要从头部投影选；两片面包都在两指之间时绝不能下降。
- 夹空的原因是 yaw，不是高度或可达范围。手的 yaw 是 `9`，面包片大约在 yaw `0`，开度为 `0.32`
  （`2.9` 厘米）。`2` 厘米厚的面包片在指垫长度上歪 `10` 度，需要约 `2.7` 厘米，所以有一根手指落在了
  面包片上，而不是面包片旁边。用 `look --cams right_wrist --z 0.785 --mark` 测量歪斜（沿手的轴线
  在 TCP 处及其两侧各 `2.3` 厘米处画标记）：从近处的标记到远处的标记，面包片中心都必须落在标记上。
- 有效的做法：手的 yaw 与面包片一致，面包片位于两指正中，装着两片时开度 `0.42`，只有一片时 `0.6`，

  去盘子那里再回来。

运行 `20261124-154720-real-eef-cc` 中使用的修正办法（没有接触）：

   `top_z = 0.66` 时，`z = 0.70` 的生菜松手和 `z = 0.725` 的第二片松手仍然能通过。只能在第一片放下
   之后再登记：那次松手在 `z = 0.68`，位于盒子内部。
2. 从 `home` 关节插值到 `(0.509, 0.149, 0.80)`，rpy `[0, 0, 0]`：原地上升。
3. 在 `z = 0.80` 沿直线到叶子上方，`(lx, ly, 0.80)`，rpy `[0, 0, 0]`。
4. 关节插值下降到悬停点 `(lx, ly, 0.711)`，使用夹取时的 rpy。从 `0.80` 直线下降被当作分支翻转而
   拒绝。

叶子落在哪里：松手 rpy 为 `[0, 5, -75]`，在 2026-11-24 的三次运行中测得。`(bx, by)` 是下层面包片的
中心：

| 松手 TCP | 结果 |
|---|---|
| `(bx - 0.01, by + 0.067)` | 叶子盖住面包片的大部分 |
| `(bx - 0.01, by + 0.039)` | 叶子盖住右半边，并在 `-y` 边缘外垂出 `5` 厘米 |
| `(bx - 0.004, by + 0.029)` | 叶子只盖住右前半边 |
| `(bx - 0.01, by + 0.07)` | 叶子盖住右半边，并垂出 `-y` 边缘和近侧边缘（第四次运行） |

叶子朝手指的 `-y` 方向垂下，垂出多少取决于手指夹在叶子长度方向上的哪个位置。同样的偏移 `by + 0.07`
在一次运行中盖住了面包片的大部分，在另一次中只盖住右半边，所以没有哪个固定偏移是可靠的。下文
“生菜搬运”中的公式（`by + 0.039`）在每种情况下都偏小。还没试过的做法：在搬运高度用头部相机看手里的
叶子，根据叶子实际垂下的位置选择松手点，就像松手前检查手里的面包那样。

2026-11-25 试过一次：在悬停点，叶子从指尖处竖了起来，它的投影中心相对 TCP 朝 `+x` 偏 `4` 厘米、
朝 `-y` 偏 `4.5` 厘米。于是移动 TCP，让这个中心落在面包上。松手时竖起的部分朝机器人方向倒回来，
叶子盖住了面包片靠左、靠近侧的那一半。竖着的叶子的投影会夸大它躺下后向前伸出的距离；根据悬停视图
修正 `y`，不要在 `x` 方向把手往回移。

### 平放

设目标面包中心为 `(bx, by)`。面包中心相对松手 TCP 有偏移，偏移量取决于面包片在两指之间的位置。

| 盘子参考位置 | rpy | 实测松手偏移 `(dx, dy)` |
|---|---|---|
| 中心约 `(0.30, -0.04)`，较远 | `[90, -10, 20]` | `(0.035, 0.042)` |
| 同上 | `[90, -10, 30]` | `(0.022, 0.040)` |
| 中心约 `(0.235, -0.04)`，较近 | `[90, -10, 20]` | `(0.023, 0.043)` |

估计式 `TCP + R * (0.003, 0, -0.037)` 比实测偏移小约 4 厘米，因为面包片在两指之间的位置会变。
