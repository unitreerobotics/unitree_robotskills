# R1-D 臂力矩前馈：作用、控制律与限制

[English](r1d_joint_tracking_feedforward.md) | 中文

## 为什么需要前馈

机器人运行时（Runtime，`third_party/robot_runtime`）只对关节做 PD 控制。持续的负载力矩不补偿时，手臂的跟随误差很大，足以让走子在途中被跟随保护终止。原因有三个：

| 原因 | 表现 |
|---|---|
| 重力没有补偿 | 静态误差乘以 kp 等于电机自报力矩 `tau_est` |
| 库仑摩擦和静摩擦 | 停留位置随到达方向变号；最大误差出现在减速段 |
| 阻尼拖拽 | Runtime 把 `dq` 目标固定为 0，`kd·dq` 在运动中一直制动 |

发送路径不是原因：加同样前馈后，50 Hz 的适配路径和 250 Hz 的直连路径结果一致。

## 控制律

实现在 `src/r1d_chess/robot/r1d_torque_ff.py`，参数在 `config/arm_torque_ff.json`。服务每 20 ms 随关节目标下发：

```
qtau = scale · g(q_cmd)                                              # 重力，在命令角处计算
     + (coulomb + load·|g|) · tanh(dq_cmd/ε_v + (q_cmd − q)/ε_e)      # 摩擦；停下后仍按误差方向帮关节越过静摩擦
     + kd · dq_cmd                                                   # 抵消 Runtime dq=0 带来的阻尼拖拽
     + clip(∫ ki·(q_cmd − q) dt, ±limit)                             # 积分：误差在窗口内才累积
最后逐关节限幅（tau_limit_nm），变化率不超过 tau_rate_nm_s
```

- 重力用 `model_urdf` 指定的动力学 URDF 计算（包内 `assets/models/r1d/r1d_arm_dynamics_reference.urdf`，连杆质量和质心由实机拟合），含 Dex1。它只用于力矩，FK/IK 仍用运动学 URDF。
- 各项都可以单独开关；`enabled=false` 时 qtau=0。
- 前馈在执行中和轮间保持时都生效。切换执行臂、出故障或结束会话时积分清零。
- 会话正常结束或故障时，先把 qtau 按变化率上限斜坡降为 0 再结束（Runtime 退出后电机会保留最后一帧命令）。
- `get_state` 返回 `arm_torque_ff` 的状态和各分项，可用来核对是否生效。
- 事务引擎不能直接给力矩：`command_arm` 的 `tau` 必须全为 0，前馈只由传输层按配置计算。

## 新机器人上的整定

`config/arm_torque_ff.json` 和动力学 URDF 是一台参考机器人的拟合结果。连杆质量和摩擦随个体不同，新机器人应重新辨识：先用 [setup/arm-calibration](../setup/arm-calibration/README.zh.md) 拟合双臂动力学 URDF，再用 [setup/joint-tracking](../setup/joint-tracking/README.zh.md) 在 Runtime 链路上验证和微调。对比测试的做法：

1. 从实测起点出发，把 TCP 竖直抬高几厘米到一个中心位姿。
2. 在中心位姿附近让 14 个关节同时做小幅双向摆动，每段动作后停留 2 s 测静态误差。
3. 比较“无前馈 / 只重力 / 重力加积分 / 全部”几种模式下的关节均方根误差和静态误差，逐项调整。
4. 全程保留跟随误差、超温、反馈过期保护，结束前把 qtau 斜坡降为 0。

没有重新整定时，先用 `get_state` 和一次空载路径验收确认跟随误差在限制内，再做抓放。

## 跟随限制

| 限制 | 值 | 说明 |
|---|---|---|
| 运行中跟随误差锁存故障 `arm_tracking_limit_rad`（每 20 ms 检查一次） | 0.20 rad | 远大于有前馈时的瞬时误差，仍远低于碰撞或卡死时的误差 |
| 执行起点关节偏差 | 0.08 rad | 覆盖轮间保持、切换手臂和静摩擦停位的离散 |
| 执行起点 TCP 偏差 | 15 mm | 介于静态误差和瞬时最大误差之间 |
| 执行起点速度 | 0.08 rad/s | 判断是否静止 |
| Runtime 速度上限、命令超时 0.15 s、过温 75 °C | — | 本体保护 |

不要为了通过检查而放宽这些阈值。

## 注意事项

- 运动学 URDF 的腕 pitch 限位只有 ±0.5236，是偏保守的软件限位，会限制 IK 的可达范围。
- 摩擦和重力参数在有限的姿态区间里辨识；在差别很大的姿态（如手臂大幅伸展）下，残差主要靠积分补。
- 结果是空载的。棋子只有 10–20 g，影响可以忽略。
- 在 Runtime 现有 PD 增益下，前馈能达到的误差有下限；要进一步降低，需要提高臂部 kp 或让 Runtime 下发非零的 dq 目标。

> 参考（参考机器人，空载，14 个关节取最大值）：
>
> | 前馈 | 关节均方根误差 | 最大静态误差 | TCP 均方根误差 左/右 |
> |---|---|---|---|
> | 无 | 49–71 mrad | 59–138 mrad | 27–40 / 20–29 mm |
> | 只重力 | 28–29 mrad | 44–46 mrad | 约 16 / 16 mm |
> | 重力 + 积分 | 13 mrad | 14 mrad | 6.8 / 7.7 mm |
> | 全部（重力、摩擦、阻尼补偿、积分） | 约 10 mrad | 约 10 mrad | 5.7 / 6.2 mm |
>
> 全部开启时关节瞬时误差最大 33–38 mrad，TCP 瞬时误差最大约 20 mm，出现在动作过渡段；电机温度不超过 55 °C。无前馈时一次走子在接近阶段因跟随误差超限被终止，已完成航点的 TCP 误差达 47–56 mm。
