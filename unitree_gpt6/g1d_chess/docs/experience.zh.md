# 抓放经验与可复用边界

[English](experience.md) | 中文

本页说明 [README](operation_manual.zh.md) 与 [round_plan](../prompts/round_plan.zh.md) 中的抓放判断方法。坐标、开爪值、姿态和腰状态须在当前设备核验。新设备先读 [首次配置](first_game_setup.zh.md)。

## 每轮重点

| 阶段 | 可复用的成功要点 | 容易重复的问题 |
| --- | --- | --- |
| 规划 | 从新头图确认实际棋局，source/target分别估计XYZ/RPY；按source首选手，完整预检不通过再换手 | 把历史坐标、source偏移或另一姿态的工具坐标搬到target；单点IK冒充整步可达 |
| source高位 | 左右在两片相对纹理面之间，前后在前端有效夹持段，合并估计一次XY争取可夹 | 追求百分百居中；分方向试探；只看张口投影而忽略棋子在夹爪后方 |
| source低位 | 棋子两侧壁进入两指有效纹理，指尖能包住侧壁，无明显压顶/夹邻子 | XY偏位用降Z补偿；只凭遮挡或二维接近拒抓 |
| 抓成与搬运 | 静止闭爪反馈满足当前验抓判据后连续搬运，异步记录原始快照 | 以夹爪非空证明抓到指定棋子，或持棋期间检索资料/计算FK |
| target低位 | 腕图沿可见格线和邻子推断目标交点，估计释放后底面中心及整枚棋子下落空间 | 仅边缘覆盖交点就放行；把外壳/阴影/顶面当落点；小FK误差掩盖明显错格 |
| 连续吃子 | 同手两段联合预检，一次execute；同侧圆盘开爪到位后高位直接去己方source | 第一段后回init、重复open/enable、再预检，造成多余停顿 |
| 收尾 | 新头图分别验source腾空、目标到格、邻子变化；离线两事件三误差与JSONL合并 | 以placed代替棋局验收；增加额外完整报告；把不明/失败样本计入均值 |

## 修正次数与能夹即可

source高位XY最多3次，前两次后立即复拍，第三次直接下降；下降后的原有低位闭爪门禁保留。两方向足以夹住即可尝试，不追求像素级完全居中。低位XY不足时保持开爪retry_high，不用普通对中不足触发failure回init；真实空抓回高位，最多真实闭爪3次，跨重规划累计。

若超过半枚棋子在纹理接触区外，而XY已可夹、只是高度导致有效接触面积不足，考虑adjust_z自动竖直下调5mm。第一次后复拍；仍仅受高度限制且已预检第二次下调时，再下调并直接闭爪，没有第三低位门禁。不能用降Z修正前后偏位或明显邻子干涉。

target低位XY保持当前实际Z/RPY，不抬升；前两次后复拍，第三次后直接原位张爪，不追加视觉审批条件。source高位与target低位修正无单次/累计距离上限，不进行修正段运动检查；执行前完整plan预检、视觉与次数、实际硬件故障处理仍保留。代码能力差异见 [runtime](runtime.zh.md)。

## 坐标与验收边界

`actual_relative_offset_xy_m`相对当前检查点实际FK，由提交器换算服务参考偏移，不能和累计参考量混加。source与target独立；source夹持位置变化会改变棋子相对工具的偏心，同一EE target不保证同一落点。换释放RPY后重新估计target XYZ，在净空高位转姿。

请求Z是模型EE坐标，不是指尖净高或棋子底面高度。棋子顶面与板面交点有视差，头图与腕图也不是同一投影。局部拟合残差小、FK误差小、稳定非空接触以及服务placed各自只提供局部证据，不能单独证明准确落格或邻子未受扰动。

实际腰须锁零并核验；模型假设零腰不能替代实测。棋盘、机位、腰姿改变后用 [board_position](../board_position/README.zh.md) 从新图重新标记。init、开爪q、抓取高度与姿态均须现场确认。

## 执行节奏与复盘

运动前备好全部脚本、stage、六/七字段评价结构。执行只做next、看本次头+执行手腕两图、立即决策并submit、继续next；5秒是响应目标，不是已保证延迟。门禁reason/evidence记录当前身份、夹持区或预计落点偏向及邻子关系；不检索历史或改代码。

结束仍只有两项：①新头图判断走棋成功/偏位；②离线计算抓成和低位批准释放两事件相对原始plan、最终生效目标、当时命令FK的三误差，结合视觉结果由finish承接JSONL并生成命名复盘。历史误差只参考，不能机械补偿；25mm只筛选学习样本。详情见 [误差闭环](xy_error_learning.zh.md)。
